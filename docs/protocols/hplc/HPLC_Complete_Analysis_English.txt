Source location:

Purpose:
To verify the actual mobile-phase flow delivered by the pump by collecting a known volume and measuring the time required.

Procedure described:

- Record the time in minutes.

Required input fields for each of the three setpoints:
- Set Flow Rate (mL/min)
- Collection Volume (mL); source value: 10.0 mL
- Time Taken (min)

Calculated fields:
- Actual Flow Rate (mL/min)
- Deviation (mL/min)
- Deviation (%)
- Absolute Deviation (%)
- Result (Complies / Does Not Comply)

Equations:

Actual Flow Rate:
Actual Flow = Collected Volume / Time Taken

For the source volume:
Actual Flow = 10.0 / Time Taken

Signed Deviation:
Deviation = Actual Flow - Set Flow Rate

Percentage Deviation:
Deviation (%) = ((Actual Flow - Set Flow Rate) / Set Flow Rate) × 100

Absolute Percentage Deviation:
Absolute Deviation (%) = ABS(Deviation (%))

Acceptance:
-1.0% <= Deviation (%) <= +1.0%

Equivalent rule:
ABS(Deviation (%)) <= 1.0%

Data validation:
- Time Taken must be greater than zero.
- Set Flow Rate must be greater than zero.
- Collected Volume must be greater than zero.
- Do not calculate if a required input is missing or invalid.

Deviation_i = x_i - Mean

TEST 7 — DETECTOR LINEARITY
----------------------------------------------------------------------

Source location: PDF pages 5 and 6. Summary also appears on PDF page 1.

Purpose:
To evaluate the relationship between Caffeine concentration and detector peak area.

Standard stock concentration:
1000 ppm.

Concentration levels:
1. 10 ppm
2. 20 ppm
3. 30 ppm
4. 40 ppm
5. 50 ppm

Number of concentration levels:
5.

Preparation entries visible in the source:
- 10 ppm: dilute 1 mL stock to 100 mL.
- 20 ppm: dilute 2 mL stock to 100 mL.
- 30 ppm: dilute 3 mL stock to 100 mL.
- 40 ppm: dilute 4 mL stock to 100 mL.
- 50 ppm: dilute 5 mL stock to 100 mL.

Required input fields for each level:
- Concentration (ppm)
- Caffeine Peak Area

Number of response values:
5 peak-area values, one at each concentration.

Required calculations:

Pearson Correlation Coefficient (r):

r = SUM((x_i - MeanX)(y_i - MeanY)) /
    SQRT(SUM((x_i - MeanX)^2) × SUM((y_i - MeanY)^2))

Where:
- x_i = concentration.
- y_i = measured peak area.
- MeanX = mean concentration.
- MeanY = mean peak area.

Linear Regression:
y = m x + b

Where:
- m = slope.
- b = y-intercept.
- x = concentration.
- y = predicted peak area.

Slope:
m = SUM((x_i - MeanX)(y_i - MeanY)) /
    SUM((x_i - MeanX)^2)

Intercept:
b = MeanY - (m × MeanX)

Coefficient of Determination:
R² = 1 - [SUM((y_i - yhat_i)^2) / SUM((y_i - MeanY)^2)]

Where yhat_i is the predicted response from the regression equation.

Additional display values:
- Pearson r
- R²
- Slope
- Intercept
- Regression equation
- Actual peak area at each concentration
- Predicted peak area at each concentration
- Residual at each concentration (Actual - Predicted)

Acceptance criterion:
The detailed acceptance statement on PDF page 6 says:
Correlation coefficient should not be less than 0.99.

Adopted acceptance rule:
r >= 0.99.

Important source discrepancy:
The summary table on PDF page 1 appears to say "less than 0.99", while the detailed procedure on page 6 says "should not be less than 0.99". Use r >= 0.99 as instructed by the user and retain this discrepancy in the source notes.

Do not replace r with R². Display both separately. The source acceptance criterion is expressed as a correlation coefficient, i.e. r.

5. CONSOLIDATED CALCULATION FORMULAS
======================================================================

The following formulas cover the calculations required by the ten tests. Use full-precision raw values for calculations; apply rounding only to displayed results.

A. Mean (Arithmetic Average)

Mean = SUM(x_i) / n

B. Individual Deviation from Mean

Deviation_i = x_i - Mean

C. Absolute Deviation

Absolute Deviation_i = ABS(x_i - Mean)

D. Sample Standard Deviation

SD = SQRT(SUM((x_i - Mean)^2) / (n - 1))

E. Relative Standard Deviation

RSD (%) = (SD / Mean) × 100

F. Actual Flow Rate

Actual Flow = Collected Volume / Time Taken

G. Flow Rate Percentage Deviation

Deviation (%) = ((Actual Flow - Set Flow) / Set Flow) × 100

H. Absolute Percentage Error

Absolute Error (%) = ABS(((Measured Value - Set Value) / Set Value) × 100)

I. Temperature Deviation

Temperature Deviation = Observed Temperature - Set Temperature

J. Pearson Correlation Coefficient

r = SUM((x_i - MeanX)(y_i - MeanY)) /
    SQRT(SUM((x_i - MeanX)^2) × SUM((y_i - MeanY)^2))

K. Linear Regression

y = m x + b

L. Regression Slope

m = SUM((x_i - MeanX)(y_i - MeanY)) /
    SUM((x_i - MeanX)^2)

M. Regression Intercept

b = MeanY - (m × MeanX)

N. Coefficient of Determination

R² = 1 - [SUM((y_i - yhat_i)^2) / SUM((y_i - MeanY)^2)]

O. Residual

Residual_i = Actual y_i - Predicted y_i

P. Carryover Percentage

Carryover (%) = (Blank Area / Carryover Solution Area) × 100

Q. Gradient Actual Concentration

Actual Concentration (%) =
[(Height_Setting - Height_0) / (Height_100 - Height_0)] × 100

R. Gradient Deviation

Deviation = Actual Concentration (%) - Setpoint (%)

S. Maximum Response

Maximum Response = MAX(all recorded response values)

T. Maximum-Response Wavelength

Maximum-Response Wavelength = wavelength associated with Maximum Response

Calculation safeguards:
- Do not divide by zero.
- Do not calculate statistics with missing required observations.
- For sample SD, require at least two observations.
- For RSD, the mean must not be zero.
- For correlation, both x and y must contain at least two valid paired values and must not have zero variance.
- For regression, the x values must not all be identical.
- Preserve raw input values and calculation precision.
- Show units with every measured or calculated value.
- Display signed deviation as well as absolute deviation where applicable.
- A missing or invalid required value must not be interpreted as a passing result.
