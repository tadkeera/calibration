HPLC.pdf, page 2.

| Point | Set Flow Rate |
|---|---:|
| A | 0.5 mL/min |
| B | 1.5 mL/min |
| C | 2.5 mL/min |

For each point, create these fields:

- Set Flow Rate.
- Collected Volume.
- Time Taken.
- Actual Flow.
- Deviation.
- Deviation Percentage.
- Absolute Error Percentage.
- Result.

Default Collected Volume:

10.0 mL

Required input count:

Three time measurements, one for each set flow rate.

Formula:

Actual Flow = 10.0 / Time Taken

Deviation = Actual Flow - Set Flow Rate

Deviation % =
((Actual Flow - Set Flow Rate) / Set Flow Rate) × 100

Absolute Error % =
ABS(Deviation / Set Flow Rate) × 100

Acceptance:

ABS(Deviation %) <= 1.0

Display:

- Deviation.
- Deviation %.
- Absolute Error %.
