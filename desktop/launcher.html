إعداد مِعيار لسطح المكتب

اختر جهاز المضيف لحفظ قاعدة البيانات محليًا ومشاركة السجلات داخل الشبكة، أو جهاز العميل للاتصال بالمضيف دون إنترنت.

لا يحتاج المضيف إلى الإنترنت. خصص عنوان IP ثابتًا للمضيف أو اسم جهاز ثابتًا، واجعل المنفذ 3010 مسموحًا في جدار حماية Windows للشبكة الخاصة فقط.
