# دليل تشغيل مِعيار على Windows دون إنترنت

## الحزمة

ملف `Miayar-Setup-1.0.0.exe` هو ملف Windows ذاتي التشغيل يتضمن التطبيق وخادم التشغيل وواجهة المستخدم وأصول التقارير. لا يحتاج إلى Node.js أو Python أو اتصال إنترنت أو تنزيل مكتبات إضافية على أجهزة المختبر.

## إعداد جهاز المضيف

يشغّل جهاز واحد فقط بوصفه **المضيف**. عند فتح التطبيق لأول مرة، اختر «هذا الجهاز هو المضيف»، ثم عيّن كلمة مرور المدير الأولية. ينشئ التطبيق قاعدة بيانات SQLite محلية في مساحة بيانات Windows الخاصة بالتطبيق ويستمع على المنفذ الداخلي `3010`.

يجب ضبط جدار حماية Windows للسماح للتطبيق على **Private networks** فقط. يوصى بمنح جهاز المضيف عنوان IP ثابتًا في شبكة المختبر، أو استخدام اسم جهاز ثابت. لا تفتح المنفذ للإنترنت العام.

## إعداد أجهزة العملاء

بعد تشغيل المضيف، افتح التطبيق على كل جهاز عميل واختر «هذا الجهاز عميل». أدخل عنوان المضيف بالشكل التالي:

```text
http://192.168.1.20:3010
```

تظهر كل السجلات والحسابات والاعتمادات نفسها لأن قاعدة المضيف هي مصدر الحقيقة. لا تنشأ قاعدة منفصلة على أجهزة العملاء، ولذلك لا يحدث تضارب عند اعتماد سجل أو تعديله من جهاز مختلف.

## النسخ الاحتياطي والاستعادة

أغلق التطبيق على جهاز المضيف قبل نسخ ملف SQLite احتياطيًا. احتفظ بالنسخ في وسيط تخزين مؤمّن ومشفّر عند الإمكان. عند الاستعادة، أعد الملف إلى موقع بيانات التطبيق على **جهاز المضيف فقط** ثم شغّل التطبيق.

> يستمر جهاز المضيف في العمل عند انقطاع الإنترنت. تحتاج الأجهزة العميلة فقط إلى اتصال الشبكة الداخلية بالمضيف؛ فإذا انقطعت الشبكة، تُستأنف العمل من العميل عند عودة الاتصال، بينما يظل المضيف قادرًا على العمل محليًا.

## حدود إصدار سطح المكتب

استعادة كلمة المرور عبر البريد غير متاحة في التشغيل دون إنترنت، لأن مزود البريد أُلغي. يغيّر المستخدم كلمة مروره من صفحة أمان الحساب بعد تسجيل الدخول، ويستطيع المدير إدارة الحسابات داخل النظام.
